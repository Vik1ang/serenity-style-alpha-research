# A 股 R10 Spec — Large-cap Re-rating Residual Gate

R10 用于核心基本面 thesis 已经成立的大市值公司，判断市场是否仍有剩余重估空间，而不是再次证明公司是否属于产业链或业务是否真实。它以 R4 的 thesis-level Shortlist 为研究入口，以 R5 公司级财务/治理红旗为优先否决层，以 R6 large-cap / mixed crowding 为市场结构前置，再分别检查估值扩张、盈利预期修正、机构持仓、业绩兑现速度和 price-in 聚合状态。R10 不把“基本面成立”等同于“仍值得重估”，也不因估值高位自动否定优质公司；它输出的是剩余重估状态，并交给交易推演层映射为研究可行动性。R10 不替代 R4/R5/R6，Biotech BD 样本还必须先通过 R9 的收入质量和反向事件覆盖层。

## 1. 五个核心规则

### 1.1 估值扩张

使用与公司盈利阶段匹配的估值指标，同时比较公司自身五年历史和行业可比公司。当前估值达到过去五年 80% 分位以上，且高于五年中位数至少 30%，命中“估值高位”。亏损或利润波动异常公司改用 PB、PS 或 EV/Sales，禁止因 PE 失真而直接判断低估或高估。历史不足五年时标数据不足，不缩短窗口制造结论。

### 1.1.1 高股息 / 公用事业估值适配

适用于水电、火电、燃气、高速、港口、银行等典型高股息板块，其主要估值锚改为“股息率－10 年国债收益率”利差的五年分位。利差收窄幅度处于五年 80% 分位以上（等价于当前利差处于五年 20% 分位以下），且当前利差低于五年中位数至少 30%，命中“高股息板块估值高位”。若 PE 与利差结论冲突，以利差为准；缺利差数据时只能标“待确权”。

### 1.2 盈利预期修正

以最近 90 日 FY1/FY2 一致预期中位数变化衡量市场新增预期。中位数上修至少 10%，且上调机构占比至少 60%，记为正向修正；变化在正负 5% 内记为预期停滞；下修至少 10% 记为负向修正；其余区间只标弱修正，不作强判断。若机构样本过少或预测日期不同步，必须标数据不足。

### 1.3 机构持仓饱和

以可核验的公募基金和陆股通合计流通股持仓衡量边际资金空间。合计持仓处于自身三年 90% 分位以上，且最新季度增量低于 0.5 个百分点或转为下降，命中“机构持仓饱和”；处于 80%—90% 分位只标“高持仓”，不触发饱和。数据缺失不得反向推断低拥挤，也不能用龙虎榜席位代替季度持仓。

### 1.4 业绩兑现速度

业绩兑现必须同时看财报前一致预期和报表质量。连续两个季度扣非利润达到或超过财报前一致预期，且毛利率或经营现金流至少一项改善，记为快速兑现；连续两个季度低于预期超过 5%，或 R4 已设 checkpoint 延迟超过两个季度，记为兑现不足；其他情况为正常兑现或数据不足。单季波动不能独立定义趋势。

### 1.5 Price-in 聚合

Price-in 使用五项信号：①估值高位；②120 日相对行业超额收益至少 30 个百分点；③最近 90 日盈利预期上修不足 5%；④机构持仓饱和；⑤连续两个季度没有正向业绩 surprise。判定“已充分定价”至少命中 4/5，且必须包含①或②。至少四项具有可靠数据后才能输出正式 R10 状态；不足四项统一标“数据不足”。

## 2. R10 入口条件与优先级

R10 入口：R4 核心 thesis = Shortlist + R5 无公司级压倒红旗 + R6 判定 large-cap / mixed crowding，方可进入 R10。若命中 R5 硬红旗，以 R5 流程为准，执行降级或 Excluded；R10 不输出剩余重估状态，因为基本面风险已经优先于估值讨论。100—1000 亿元公司条件适用，详见市值适用范围段。

### 市值适用范围

- **≥1000 亿元**：默认适用 R10，但仍须满足至少四项可靠数据的底线。
- **100—1000 亿元**：条件适用；最近 90 日至少有 5 家独立机构提供 FY1/FY2 预测，并有至少两个连续季度的可核验机构持仓数据。
- **<100 亿元**：默认不适用 R10，继续使用 R6 Small-cap relay 和既有 thesis-level 分桶。

## 3. 四档剩余重估状态

Price-in 信号数量相同时，用盈利预期和业绩兑现方向区分状态；信号数量只衡量定价程度，不能替代基本面方向。

### 3.1 仍有重估空间

Price-in 命中不超过 2/5，盈利预期正向修正或业绩快速兑现至少命中一项，且不存在负向修正、兑现不足或 R5 硬红旗。该状态表示核心 thesis 已确认，但市场预期、估值或持仓尚未同时饱和。

### 3.2 等待业绩消化

命中估值高位或 120 日显著超额收益，Price-in 共命中 2—3/5，盈利预期未下修 10%，且没有连续两个季度兑现不足。若与“仍有重估空间”同为 2/5，本档要求预期/兑现仅为停滞或正常，而非正向修正或快速兑现。

### 3.3 已充分定价

Price-in 至少命中 4/5，且必须包含估值高位或 120 日显著超额收益，同时基本面仍成立、未触发重估反转风险。该状态不是 Excluded，而是说明新增预期大部分已经进入价格，交易层应等待新的财务或估值条件。

### 3.4 重估反转风险

R5 公司级压倒红旗未命中时，若估值高位或 120 日显著超额收益至少命中一项，同时出现盈利预期下修至少 10%或连续两个季度兑现不足，则进入重估反转风险。若随后命中 R5 硬红旗，应立即退出 R10，由 R5 接管降级或 Excluded 判断。

## 4. 跟 R4 / R5 / R6 / R9 的接口

- **R4**：提供已经确认的核心 thesis、证据状态和时间窗口；未进入 Shortlist 的 thesis 不进入 R10。
- **R5**：提供公司级红旗前置过滤并拥有最高否决优先级；R10 不覆盖持续经营、审计、债务或重大治理风险。
- **R6**：提供市值档位、large-cap / mixed crowding 以及价格、成交和传播证据；R10 在此基础上判断剩余重估空间。
- **R9**：Biotech BD thesis 先通过收入质量、混合态和 C1—C3 覆盖层；仍处 Watchlist 或反向事件待澄清时不进入 R10。

R10 只读取上述模块输出，不反向改写其分桶、红旗或市场结构规则。

## 5. 交易推演层衔接

R10 固定输出以下字段，并交给 `trading-scenario.md` 映射：

```text
R10 剩余重估状态：[四档之一 / 数据不足]
Price-in 命中：[X/5；具体项目]
基本面方向：[正向修正 / 停滞 / 负向修正]
兑现状态：[快速 / 正常 / 不足 / 数据不足]
交易推演映射：[可交易研究对象 / 等待触发 / 仅观察 / 回避交易 / 数据不足]
下一验证点：[估值、预期、财报、持仓或成交结构]
```

默认映射：仍有重估空间 → 可交易研究对象；等待业绩消化 → 等待触发；已充分定价 → 仅观察；重估反转风险 → 回避交易；不足四项可靠数据 → 数据不足。该映射不输出买卖、仓位、目标价或止损价。

## 6. Worked Example 草稿：赛力斯

**证据截止日期：待 Vik1ang 确认**

**事前判断：仅使用截止日期前公开信息。**

### 6.1 R10 入口

R4 已将新能源整车 / 问界主业 thesis 列为 Shortlist；既有案例未识别 R5 公司级压倒红旗；公开市值处于千亿元以上，应按 R6 Large-cap crowding 处理。因此该 thesis 原则上满足 R10 入口，但最终判断仍受证据截止日期约束。

### 6.2 五项 Price-in 初判

1. **估值高位**：未明确披露五年估值分位及相对中位数溢价，暂不命中。
2. **120 日相对行业超额收益**：未明确披露，暂不命中。
3. **盈利预期上修不足 5%**：缺最近 90 日 FY1/FY2 一致预期序列，未明确披露。
4. **机构持仓饱和**：缺三年持仓分位和最新季度增量，未明确披露。
5. **连续两个季度无正向 surprise**：已有收入、利润和现金流事实，但缺财报前一致预期基准，未明确披露。

当前五项均未形成可核验命中，低于四项数据底线，不能把“千亿市值、强关注”直接写成已充分定价。

### 6.3 事前状态与推演

R10 剩余重估状态：数据不足。主业基本面确认不等于剩余 Alpha 已确认；在补齐估值分位、120 日超额收益、90 日盈利预期、机构持仓和财报 surprise 前，交易推演维持“等待触发 / 数据不足”。下一验证点是取得同一截止日期下的五项数据快照，再按四档状态重新判定。

### 6.4 后续验证

记录证据截止日期后的实际估值、盈利预期、机构持仓、季度兑现和相对收益结果，不回写原始分桶或事前判断。
