# A 股 R9 Spec — Biotech BD 收入质量 Gate

R9 解决百利天恒案例暴露的 materiality 结构性缺口：巨大 upfront 或里程碑付款会轻易越过“收入占比 ≥10% / 合同金额+时间”门槛，但它确认的对象可能只是核心资产价值、合作方背书和阶段性现金流，不等于持续盈利、产品销售收入或平台可复制性已经成立。R9 不替代 R1-R8：R4 仍负责 thesis-level 分桶和公告反证，R5 仍负责公司级财务/治理红旗，R6 仍负责市场结构，交易推演层仍负责非投顾状态映射。R9 只在 Biotech / 创新药 / ADC / license-out / BD 收入场景下加一层“收入质量”标签，把 upfront、near-term milestone、development milestone、sales milestone、royalty 和自营销售拆开，防止把一次性收入当成长期报表拐点。

## 1. BD 收入类型拆解

### Upfront / 首付款

首付款是最强的外部资产验证之一，说明合作方愿意为管线权益预付资金，通常可构成合同金额+时间和现金流 confirmation。但它通常是一次性或阶段性授权收入，不能直接外推为持续产品销售收入。处理：可支持核心资产 thesis 进入 Shortlist，但持续盈利 thesis 仍需单独验证。

### Near-term milestone / 近期或有付款

近期里程碑通常绑定明确临床、监管、交割或项目推进节点，确定性高于远期里程碑，低于已到账首付款。处理：若公告写明触发条件、金额和时间窗口，可作为强 checkpoint；若只是潜在上限，不能作为已确认收入。

### Development milestone / 开发与注册里程碑

开发/注册里程碑依赖临床数据、适应症推进、注册申报、审评和获批，路径长且失败概率高。处理：可证明合作路径和未来弹性，但除非已经触发或接近明确节点，否则只能作为 Watchlist catalyst，不能替代收入 confirmation。

### Sales milestone / 销售里程碑

销售里程碑依赖商业化上市后的销售额达标，受疗效、安全性、竞争格局、医保/支付、渠道和定价影响。处理：不能提前资本化为高确定性收入；只有产品上市、销售爬坡和达标条件明确时，才可提高权重。

### Royalty / 销售提成

Royalty 是更接近持续收入的 BD 类型，但前提是产品已经商业化并产生销售。处理：若披露 royalty rate 或销售分成机制，可作为持续性收入标签；若只知道存在 royalty 权利但无销售基数，仍属于长期 optionality。

### 自营销售 / 产品销售收入

自营销售是最接近持续经营质量的收入，需要看上市产品收入、毛利率、销售费用率、医保/支付、渠道覆盖和现金回款。处理：若连续多个季度验证，可支持持续盈利 thesis；若仍处早期放量，需看费用率和现金流是否吞噬收入。

## 2. BD 收入确认强度 6 级

### Level 1：自营销售连续验证

判断问题：是否已有产品销售收入连续多个季度增长？毛利率、销售费用率和现金回款是否匹配？是否不依赖一次性 BD 收入？处理：可支持持续盈利 thesis；若利润仍被研发/销售费用吞噬，保留现金流和费用率风险标签。 L1 连续验证最小口径：至少 2 个连续季度（半年报或 4 个单季）同向增长，或 1 个年度同比 + 季度环比不出现连续 2 季度下滑。仅 1 个年度同比不足以判 L1，只能算 L1 待确权。

### Level 2：royalty / 销售分成已持续兑现

判断问题：合作产品是否已商业化并产生销售？royalty 或销售分成是否已进入财报并连续兑现？是否披露 rate、区域或适应症口径？处理：可作为持续性收入 confirmation；若只有单季度或基数很低，仍需观察。

### Level 3：milestone 已触发并到账

判断问题：是否已有临床、注册或销售里程碑触发、到账或进入财报？节点是否来自独立阶段而非同一笔付款拆分？处理：单笔 milestone 增强核心资产 confirmation，但持续性仍为弱；两个以上独立阶段 milestone 到账，可把 BD 收入持续性提升至中，但仍不能等同持续产品销售或持续盈利。

### Level 4：已到账 upfront / 已确认首付款

判断问题：是否已公告到账或财报确认？金额是否不可撤销、不可抵扣或收入确认口径清晰？合作方是否为高质量 MNC 或产业方？处理：核心资产 thesis 可进入 Shortlist；持续盈利 thesis 不能自动 Shortlist，必须标注“收入质量：upfront”。

### Level 5：明确近期 milestone checkpoint

判断问题：公告是否披露近期付款条件、金额、时间窗口或监管/临床节点？触发路径是否可验证？处理：属于 Watchlist → Shortlist 的强 checkpoint；未触发前不得计入已实现 materiality，只能写“等待触发”。

### Level 6：远期潜在总额 / royalty 权利未兑现

判断问题：是否只是 development / sales milestone 上限或 royalty 权利？触发条件是否远、失败概率是否高，且产品尚无销售基数？处理：只能作为弹性上限和长期 optionality，不作为收入确认；禁止把潜在总额全部资本化。

### 混合态聚合规则

BD 合同按收入组件分别定级，同一公司可以同时命中多个 Level，不用单一 Level 覆盖全部 thesis。L4 + L5 时，已到账 upfront 支持核心资产 Shortlist，未触发 milestone 和持续盈利保留 Watchlist / 等待触发；L3 只提高 BD 执行可信度，持续盈利升级仍需 L2 持续 royalty 或 L1 连续产品销售，并通过 R5 行业校正。

持续性赋值不取最高 Level、不平均：满足 L2 持续 royalty 或 L1 连续产品销售 = 强；满足 L3 两个以上独立阶段 milestone 到账 = 中；仅 L3 单笔、L4 upfront 或 L5 近期 checkpoint 未触发 = 弱。该标签只衡量 BD 收入可重复性，不代表公司整体盈利持续性；整体盈利仍需结合费用率、现金流和 R5 红旗判断。

### 合作方反向事件覆盖层

正向 Level 记录已发生的收入和资产确认事实，合作方后续减值、暂停、退权或终止不得回写抹除原 Level，但必须作为独立覆盖层调整当前 thesis 分桶。

- C1：合作方年报/中报对授权资产单独披露减值，且减值金额 ≥1000 万美元或 ≥资产取得对价的 30%（取两项阈值中绝对值更大者）；或合作方明确降低优先级、移出重点管线，但未披露权益终止。历史 L4/L3 保留；海外 BD thesis 降为 Watchlist — 待权益状态与开发计划澄清。
- C2：正式暂停开发、停止入组、监管临床暂停或合作方明确不再推进。海外 BD thesis 为 Watchlist / Excluded 候选；国内自营 thesis 单独判断。
- C3a 负向退权：合作方退权 / 合同解除 / 资产失效（药物退市、临床失败、权益丢失）。海外 BD thesis 进入 Excluded；已到账 upfront 仍保留为历史 L4。
- C3b 权利回归后继续自营：合作方退权但上市公司收回资产 / 权益 / 商业化权利。海外 BD thesis 视为失效（合作路径中断），但应同步建立新自营销售 thesis，从 L1 待确权起步。已到账 upfront 仍保留为历史 L4，但不再为旧 BD thesis 提供确认。

C3a 与 C3b 的区分必须以合作方公告 + 上市公司公告为依据；C3b 触发后未建立新自营 L1 证据前，海外资产仍处于 Watchlist 待澄清。

解除覆盖需要合作方或公司正式披露继续开发/权益有效，并至少出现新的开发节点、里程碑、注册进展或权益状态确认。仅管理层口头表态不足以恢复。

### 地域双轨

国内自营销售与海外 BD 权益分别定级、分别分桶；任何一侧的确认或反向事件不得自动覆盖另一侧。

## 3. Materiality 10% 门槛扩展：BD 收入质量标签

Biotech BD 公司通过 materiality 门槛时，必须附加收入质量标签，格式为：`Materiality：已满足 / 收入质量：[upfront / milestone / royalty / 自营销售 / 混合] / 持续性：[强 / 中 / 弱]`。默认规则：upfront ≥5 亿元或单笔 milestone ≥1 亿元可支持核心资产 Shortlist；连续 2 个以上 milestone、royalty 或产品销售收入验证后，才可提高持续性标签。

禁止写法：只因潜在总交易额巨大，就写“收入弹性已确认”。潜在总额只能作为上行情景；已到账 upfront 和 milestone 才能作为 realized / disclosed materiality。若 BD 收入占比很高但全部来自一次性首付款，结论应是“核心资产价值确认”，不是“经营模型持续盈利确认”。

## 4. R5 财务红旗行业校正：Biotech 亏损与现金流

Biotech 持续亏损、研发费用高和经营现金流为负不应机械触发 Excluded，因为临床期公司天然消耗现金。R5 红旗在 Biotech 场景下需行业校正：看现金 runway、融资能力、临床阶段、合作方质量、后续里程碑可能性、研发管线集中度和是否存在非标审计/ST/退市风险。亏损本身是风险，不等于反证。

校正规则：若现金 runway 低于 12 个月、融资窗口关闭、核心临床失败、或持续亏损叠加重大稀释压力，则降级 Watchlist / Excluded；若有已到账 upfront、强合作方、充足现金和明确临床/注册节点，则允许核心资产 thesis 保留 Shortlist，但交易推演必须标注现金消耗和再融资风险。

## 5. 交易推演层：BD 资产兑现型状态模板

BD 资产兑现型样本必须把“资产价值已验证”和“交易可行动性”分开。核心资产已由高质量 upfront / milestone 验证时，可写“可交易研究对象”；若后续临床、注册、里程碑或商业化节点未触发，则公司整体常见状态是“等待触发”。不得因为潜在总额巨大而忽略估值、临床失败和融资风险。

推荐输出：`当前交易状态：核心资产可交易研究对象 / 持续盈利等待触发 / 后续管线仅观察`。关键 checkpoints 包括后续 milestone 触发、临床数据、注册申报/获批、产品销售收入、royalty 兑现、现金 runway 和融资安排。不宜交易条件包括把潜在总额全部资本化、临床失败、milestone 延迟、现金消耗超预期和高估值拥挤。 若命中 C1，核心资产状态降为 Watchlist — 待澄清；命中 C2 时暂停升级，并按开发状态判为 Watchlist / Excluded 候选；命中 C3 时海外 BD thesis 为回避交易。历史 upfront 不因反向事件消失，但不能继续单独支撑当前可交易状态。
