# A 股 R6 Spec — 市场结构数据最低证据标准

R6 定义 R2/R3 市场结构判断的数据底线：缺数据先标不足，证据闭合后再硬判风险定价。

## 8.4 市场结构数据的最低证据标准

### 1. R2 / R3 最低数据包

#### 市值档位数据日期

跑票必须先记录市值档位和估值日期，格式为：`市值档位：[≥1000 亿 / 100-1000 亿 / <100 亿]；市值/流通市值：X 亿元；数据日期：YYYY-MM-DD`。若数据日期距离研究日超过 5 个交易日，标记“市值档位数据陈旧”，不得直接套用 large-cap crowding / mixed / small-cap relay 判断。


#### 行情快照字段包

当可用行情工具存在时，A 股跑票必须先拉一份可复核的 market snapshot，并在输出中写明数据日期和来源。最低字段：

- 实时/收盘价、前收盘价、涨跌幅；
- 总市值、流通市值、市值档位；
- PE_TTM、PB、PS_TTM；
- 最近 5 日和 60 日涨跌幅，或可由 K 线计算的等价区间涨跌幅；
- 当日成交额、换手率、量比；
- 涨停价、跌停价、是否涨停/跌停/接近涨停；
- 最近 20–60 个交易日 K 线，用于计算区间涨幅、成交额放大和高位拥挤；
- 可用时补融资融券余额/占比、资金流、龙虎榜、异动公告和热榜。

若行情工具缺少北交所、小票或特定市场数据，必须标注“行情数据源无覆盖”，不能把缺数据当成无拥挤或无流动性风险。

#### 连板 / 涨跌幅

最低要求：

- 最近 5-10 个交易日涨停次数；
- 是否连续涨停；
- 是否一字板；
- 是否出现开板剧震、天地板、炸板回封；
- 是否触发交易异常波动标准。

判断：

- 单次涨停或单日大涨 → 通常 R1；
- 2 个及以上涨停、连续大涨或触发异动 → R2；
- 连板高度较高 + 一字板 / 开板剧震 / 异动公告 → R3 候选。

#### 异动公告 / 风险提示

最低要求：

- 是否有交易异常波动公告；
- 是否有严重异常波动公告；
- 是否有风险提示、澄清公告、监管问询或交易所关注；
- 公告是否提到核心 thesis、业务占比、无规模化、不确定性。

判断：

- 仅“生产经营正常” → R2 风险标签；
- 公告命中核心 thesis 且构成强反证 → R3；
- 异动公告 + 多日涨停 + 财务 confirmation 缺失 → R3 候选。

#### 龙虎榜

最低要求：

- 是否登上龙虎榜；
- 买卖席位是否高度集中；
- 是否有知名游资或量化席位接力；
- 买一/买五集中度；
- 是否出现机构席位，机构是净买还是净卖。

判断：

- 有龙虎榜但席位分散 → R2 辅助证据；
- 高度集中接力、游资主导、高位分歧 → R3 辅助证据；
- 龙虎榜不能单独证明 R3，必须结合价格或公告。

#### 成交额 / 换手率

最低要求：

- 最近 5 / 10 / 20 日成交额均值；
- 当前成交额相对过去均值的倍数；
- 换手率是否显著高于历史区间；
- 流通市值和自由流通盘大小。

判断：

- 成交额和换手温和放大 → R1/R2；
- 高位巨量、换手显著异常但无财务公告 → R2/R3；
- 小流通盘下的异常成交要提高拥挤权重。

#### 热榜 / 社媒 / 短线复盘

最低要求：

- 是否进入同花顺热股榜、东方财富热榜、雪球热门讨论；
- 是否被短线复盘、题材复盘、游资复盘反复点名；
- 热点关键词是否和当前 thesis 一致；
- 是否出现市场传闻与公司公告不一致。

判断：

- 热榜只能证明传播阶段，不证明基本面；
- 热榜 + 连板 + 公告反证 → R3 强辅助；
- 热榜但无价格异动 → Stage 2 / R1-R2，不硬判 R3。

#### 监管问询 / 关注函

最低要求：

- 是否有交易所关注函、监管问询、年报问询、并购问询；
- 问询是否指向核心 thesis、并购标的、业绩真实性、商誉、资金占用或信息披露；
- 公司回复是否降低 thesis 强度。

判断：

- 问询本身不等于反证；
- 问询 + 公司回复暴露占比低、不确定性、无规模化 → R3 或 Excluded；
- 问询未回复前，标 R2 / 数据不足，不硬判结论。

### 2. 缺数据时怎么处理

缺数据时默认保守处理为：

> R2 / 数据不足

适用场景：

- 看到涨停，但缺连板高度；
- 看到热榜，但缺成交额和异动公告；
- 看到公司澄清摘要，但缺公告原文；
- 看到龙虎榜传闻，但缺席位明细；
- 看到媒体报道，但缺交易所或公司公告。

可以硬判 R3 的边界：

- 连续涨停 + 异动公告 + 公司强反证；
- 高位一字板 / 开板剧震 + 无财务 confirmation；
- 严重异常波动公告 + 核心 thesis 被公司否认；
- ST/退市/亏损红旗 + 连板炒作；
- 多个独立市场结构信号一致，即使缺龙虎榜，也可判 R3。

不能硬判 R3 的边界：

- 只有雪球/股吧热度；
- 只有单日涨停；
- 只有媒体说“游资炒作”；
- 只有公告模板“经营正常”；
- 只有成交额放大但缺价格结构和公告。

缺数据输出必须写：

> 当前缺 [数据类型]，市场结构只能标 R2 / 数据不足，不能硬判 R3。

### 3. Large-cap crowding vs Small-cap relay

R3 判断必须区分市值档位。大市值龙头的两连板、机构换手和高成交额，通常是 **large-cap crowding**；小票的五连板、游资接力和一字板，通常是 **small-cap relay**。两者都可能是 R3，但风险含义不同。

#### ≥1000 亿：Large-cap crowding

最低要求：连续大涨或涨停、成交额显著放大、机构/北向/大资金换手、异动公告或公司澄清。处理：不按小票接力理解，重点看估值透支、机构分歧、成交拥挤和 thesis 是否被 price-in。

#### 100-1000 亿：Mixed crowding / relay

最低要求：连板或连续大涨、龙虎榜/机构席位、热榜扩散、异动公告。处理：同时检查机构重估和短线接力，若财务 confirmation 不足，通常标 R2/R3 过渡或 R3 候选。

#### <100 亿：Small-cap relay

最低要求：连板高度、一字板/开板剧震、游资席位集中、换手异常、题材复盘连续点名。处理：更关注流动性、接力退潮、强反证和财务红旗；小票 R3 对 Shortlist 杀伤更强。

若市值档位缺失，不能直接套用小票连板标准；先标“市值档位数据不足”，再按已有价格、公告和成交证据保守判断。

### 4. 跟 8.1 thesis-level 衔接

市场结构数据默认是公司级信号，但必须映射回 thesis。

公司级 R3：

- 连板、异动公告、龙虎榜、成交额异常通常发生在公司层面；
- 如果市场炒作多个 thesis，公司级 R3 覆盖所有 thesis；
- 公司级 R3 不代表所有 thesis 被反证，只代表价格风险覆盖全公司。

单 thesis R3：

- 若公告、热榜、媒体、复盘明确指向某一 thesis，则该 thesis 单独标 R3；
- 例如公司只澄清机器人业务，则机器人 thesis R3/Excluded，不自动否定液冷 thesis；
- 若市场主要炒作 A thesis，但 B thesis 仍未传播，B thesis 可保留 Watchlist，但公司级风险仍要提示。

reconcile 规则：

- 公司级 R3 + thesis confirmation 缺失 → 该 thesis 不进 Shortlist；
- 公司级 R3 + 某 thesis 有强 confirmation → 可保留研究，但加价格风险标签；
- 单 thesis R3 不自动排除其他 thesis；
- 若多个 thesis 都被市场混炒，默认公司级 R3。

### 5. 数据源优先级

#### 第一优先级：交易所 / 巨潮 / 公司公告原文

包括：

- 上交所 / 深交所公告；
- 巨潮资讯公告；
- 异动公告、风险提示、澄清公告；
- 问询函和回复；
- 并购、财报、业绩预告。

用途：判断公告反证、异动标准、监管风险和核心 thesis 是否被公司确认或否认。

#### 第二优先级：交易行情与龙虎榜数据

包括：

- 交易所龙虎榜；
- 东方财富、同花顺、Wind、Choice 等行情；
- 连板高度、成交额、换手率、流通市值。

用途：判断 R2/R3、资金集中度、流动性和拥挤程度。

#### 第三优先级：热榜 / 社媒 / 短线复盘

包括：

- 同花顺热股榜；
- 东方财富人气榜；
- 雪球热门讨论；
- 短线复盘、题材复盘。

用途：判断传播阶段和题材来源，不用于 demand proof。

#### 第四优先级：媒体和券商研报

包括：

- 财联社、证券时报、上证报、21 财经等；
- 券商研报和行业点评。

用途：作为发现入口和交叉验证，不替代公告原文、交易数据和公司披露。

### 6. 已知会失真的情况

第一，**热榜高不等于 R3**。热榜只说明传播强，若没有连板、异动公告或成交结构，最多 R1/R2。

第二，**龙虎榜游资不等于 thesis 错**。游资接力说明风险定价升高，但不能单独反证基本面。

第三，**缺数据时过度保守**。R2 / 数据不足可能漏掉真实 R3。解决：列明缺失数据，等待补齐，不假装确定。

第四，**公司级价格信号误伤单 thesis**。公司连板可能由 A thesis 引发，不代表 B thesis 被市场充分定价。解决：价格信号先公司级，再映射 thesis。

第五，**小流通盘制造假拥挤**。小票少量资金可造成成交异常和涨停。解决：结合流通市值、自由流通盘和换手率。

第六，**媒体复述公告导致重复计数**。同一信息被多个媒体转载，不等于多个独立信号。解决：回到公告原文去重。
