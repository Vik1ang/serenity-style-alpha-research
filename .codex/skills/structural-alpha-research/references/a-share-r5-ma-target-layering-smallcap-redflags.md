# A 股 R5 Spec — 并购 / 新设业务载体分层与公司级财务/治理红旗

R5 处理两个低耦合但高杀伤问题：并购 / 新设业务载体分层，以及 A 股公司级财务/治理红旗如何覆盖 thesis。该红旗层适用于所有市值，小票只是高权重场景。

## 8.2 并购 / 新设业务载体分层

### 1. 标的要分几层

并购类、新设子公司、控股子公司、合资平台或项目公司 thesis，都必须把业务载体拆成四层，不能把收购完成、设立完成或控股完成直接等同于新业务兑现。

第一层：**现有主营**。标的或业务载体当前真实产生收入和利润的业务，例如 Asetek 的高性能桌面 PC 液冷，或新设平台承接的原有成熟业务。  
第二层：**目标新业务**。市场真正交易的未来方向，例如数据中心液冷、AI/HPC 客户、国内数据中心适配。  
第三层：**停摆 / 弱化业务**。标的过去做过但暂停、收缩、亏损或客户流失的业务。  
第四层：**重启路径**。新东家是否能把目标新业务重新商业化，包括技术、客户、产能、认证、销售渠道和本地化。

只有第二层和第四层能支持“新 alpha thesis”。第一层只能提供收入底座，不能自动证明目标新业务成立；新设/控股子公司若尚无收入，也不能因“平台成立”直接进入 demand proof。

### 2. 每层怎么验证

#### 现有主营

验证重点：

- 标的历史收入、毛利率、净利率；
- 主要客户和客户集中度；
- 是否并表、并表时间和会计口径；
- 收购后是否维持原有订单和客户；
- 对上市公司收入和利润的实际贡献。

判断：现有主营可以支持“并表增厚” thesis，但不能支持“新产业链瓶颈” thesis。

#### 目标新业务

验证重点：

- 是否已有明确产品；
- 是否有目标客户、认证、订单、合同；
- 合同金额和交付时间；
- 是否进入目标客户供应链；
- 是否可在 12-24 个月内进入收入确认。

判断：缺合同金额+时间或客户订单，只能 Watchlist — Early Optionality。

#### 停摆 / 弱化业务

验证重点：

- 停摆原因是需求不足、技术落后、亏损、客户流失还是战略收缩；
- 停摆时间多长；
- 过去客户是否仍可恢复；
- 竞争格局是否已经变化；
- 重启是否需要额外 capex、研发或认证。

判断：停摆业务不能按“已有业务”处理，必须重新验证 demand 和客户。

#### 重启路径

验证重点：

- 新东家是否有渠道、客户或中国市场资源；
- 是否披露重启计划、投入金额、产能安排；
- 是否已有试点客户或订单；
- 是否产生新增费用、商誉、债务或整合压力；
- 是否有明确财务窗口。

判断：重启路径没有 checkpoint，就不能从 optionality 升级。

### 3. 并购 / 新设业务载体怎么跟 thesis-level 分桶衔接

并购类和新设/控股子公司载体必须先做 thesis-level 拆分，再做业务载体内部业务分层。

推荐格式：

```text
公司 / 收购标的或新设载体现有主营 → 并表或成熟收入 / 12 个月 / 待收入确认
公司 / 收购标的或新设载体目标新业务 → 新客户或新场景 / 12-24 个月 / 待合同
公司 / 收购标的或新设载体停摆业务 → 重启路径 / 24 个月 / 待重启 checkpoint
```

分桶规则：

- 现有主营已并表且贡献可量化 → 可 Watchlist 或 Shortlist，取决于 materiality；
- 目标新业务有合同金额+时间 → 可进入 Shortlist 候选；
- 目标新业务只有市场联想 → Watchlist — Early Optionality；
- 停摆业务无重启 checkpoint → Excluded 或 Watchlist，不能 Shortlist；
- 收购产生商誉/债务压力 → 公司级风险覆盖所有 thesis。

并购 / 新设业务载体 thesis 不能用“标的有收入”“平台已成立”替代“目标新业务有收入”。

### 4. 已知会失真的情况

第一，**把标的现有主营误当目标新业务**。例如 PC 液冷收入被市场当成数据中心液冷验证。解决：现有主营和目标新业务必须分桶。

第二，**把历史客户当当前客户**。过去给 HPE/Fujitsu 交付，不代表现在仍有订单。解决：客户必须有当前合同、订单或管理层/公告确认。

第三，**忽略停摆原因**。停摆可能来自需求不足，不是被收购后自然恢复。解决：必须解释为什么这次能重启。

第四，**忽略商誉和对价压力**。收购可能增厚叙事同时增加减值风险。解决：商誉/债务进入公司级风险覆盖层。

第五，**把并表收入当 alpha 弹性**。并表收入可能只是财务合并，不代表瓶颈需求增长。解决：区分 accounting uplift 和 demand-driven alpha。

## 8.5 公司级财务/治理红旗与 A 股四件合流

### 1. 红旗类型

A 股公司级财务/治理红旗至少包含六类，适用于所有市值；小票只是高权重场景，大市值龙头也可能被再融资、商誉、扣非恶化或股东行为压制。

第一类：**控股股东质押 / 冻结 / 减持压力**。高比例质押、司法冻结、被动减持会改变风险定价。  
第二类：**商誉减值风险**。并购标的业绩承诺、亏损、整合失败、估值过高会杀死 optionality。  
第三类：**ST / 退市 / 持续经营风险**。亏损、净资产为负、审计意见、交易类退市风险直接压倒 thesis。  
第四类：**再融资压力**。定增、可转债、债务到期、现金流缺口、募投饥渴会稀释股东。  
第五类：**应收 / 存货异常**。收入增长若伴随应收和存货异常，可能不是高质量 demand proof。  
第六类：**业绩预亏 / 扣非恶化**。题材上涨但扣非亏损扩大，说明 thesis 尚未进入经营质量。

这些红旗不是补充备注，而是 Shortlist 前的风险覆盖层。

### 2. 红旗怎么嵌入 4 件 spec

#### 嵌入政策 / 周期前置

政策背景通过后，立即检查公司是否有财务生存能力。政策支持不能覆盖 ST、退市、质押爆仓、债务到期或持续经营问题。

处理：若红旗压倒，政策/周期最多给 Watchlist，不允许 Shortlist。

#### 嵌入倒序信息传播

红旗会放大题材传播的危险性。若公司带质押、ST、商誉、再融资或扣非恶化压力，同时进入 Stage 2/3 热度，说明市场更可能在交易壳、情绪或拥挤换手。

处理：传播越热，红旗权重越高。

#### 嵌入重估触发路径

confirmation 不只看收入，也要看质量。订单、并表或收入增长如果伴随应收、存货、商誉、债务或扣非恶化，不能直接视为强 confirmation。

处理：收入确认必须经过质量过滤。

#### 嵌入涨跌停风险定价

红旗与 R2/R3 叠加时，风险定价优先。连续涨停 + ST/亏损/质押/减持/再融资，是典型退潮风险组合。

处理：默认降级 Watchlist 或 Excluded。

### 3. 红旗 vs thesis 分桶

红旗分两类：公司级压倒和 thesis-level 压倒。

#### 公司级压倒

影响所有 thesis：

- ST / 退市风险；
- 持续经营重大不确定性；
- 控股股东高危质押或司法冻结；
- 大额债务到期且现金流不足；
- 重大商誉减值风险；
- 审计非标或财务真实性风险。

处理：即使某 thesis 有业务入口，也不能 Shortlist；严重时公司级 Excluded。

#### thesis-level 压倒

只影响特定 thesis：

- 某收购标的商誉风险；
- 某新业务应收异常；
- 某订单客户回款差；
- 某募投项目延期；
- 某业务库存积压。

处理：只压制对应 thesis，不自动否定其他 thesis。

#### reconcile 规则

- thesis 好但公司级红旗强 → 公司级 Watchlist / Excluded；
- 公司稳但单 thesis 红旗强 → 该 thesis Watchlist / Excluded；
- 多个中等红旗叠加 → 等同一个强红旗处理；
- 红旗未量化 → 标“数据不足”，不能假装无风险。

### 4. 已知会失真的情况

第一，**把亏损公司一律排除**。早期周期股或转型公司可能亏损但有真实订单。解决：区分结构性亏损、周期底部亏损和持续经营风险。

第二，**把质押当绝对否定**。质押比例高不一定立刻爆仓。解决：看质押比例、平仓线、股价位置、补充质押能力和减持公告。

第三，**把商誉当自动风险**。有商誉不等于会减值。解决：看标的业绩、承诺完成率、现金流和并购逻辑。

第四，**忽略红旗之间的叠加**。单个红旗可能可控，多个红旗叠加会改变 bucket。解决：红旗要组合判断。

第五，**把财务红旗当短期交易信号**。红旗不一定阻止短线涨停，但会影响 Shortlist。解决：红旗用于研究分桶，不用于预测短线价格。

### 5. 公司级红旗量化触发线

量化阈值用于 Shortlist 前的公司级风险覆盖。单个极端红旗可触发 Excluded 候选；两个以上强红旗叠加时，默认 Excluded，除非存在已披露订单、合同金额+时间、现金流改善等强验证。所有指标必须基于最新可披露财报，写明数据日期（YYYY-MM-DD）。

| 指标 | 阈值 | 触发动作 | 数据日期要求 |
|---|---|---|---|
| 资产负债率 | >70% 为强红旗；>85% 为 Excluded 候选；>90% 默认 Excluded，除非强验证 | Watchlist / Excluded 候选 | 最新可披露财报，YYYY-MM-DD |
| 货币资金 / 短期有息债务 | <0.3 为强红旗；<0.15 为 Excluded 候选 | Watchlist / Excluded 候选 | 最新可披露财报，YYYY-MM-DD |
| 毛利率 | 制造业/材料类连续 2 年 <5%，需行业校正 | Watchlist；若叠加亏损/高债务则 Excluded 候选 | 最近两年年报，YYYY-MM-DD |
| 未弥补亏损 / 实收股本 | 未弥补亏损超过实收股本 1/3 | 强红旗；叠加亏损和短债压力则 Excluded 候选 | 最新公告或年报，YYYY-MM-DD |
| 扣非净利润 | 扣非连续 2 年亏损 | Watchlist；叠加 R3 或短债压力则 Excluded 候选 | 最近两年年报，YYYY-MM-DD |
| 流动比率 + 速动比率 | 流动比率 <0.5 且速动比率 <0.3 | 强红旗；叠加现金短债缺口则 Excluded 候选 | 最新可披露财报，YYYY-MM-DD |
| 经营现金流 | 连续 2 年为负，或与收入趋势持续背离 | Watchlist；若同时收入增长、现金流恶化则提高一档风险 | 最近两年年报，YYYY-MM-DD |
| 应收 + 存货 / 收入 | 显著上升，且收入增长没有现金流匹配 | Watchlist；若用于支撑 demand proof，则该 thesis 降级 | 最新可披露财报，YYYY-MM-DD |
| 审计非标 / ST / 退市风险提示 | 出现非标审计、ST/退市风险或持续经营重大不确定性 | Excluded 候选；严重时公司级 Excluded | 最新审计报告、公告或交易所风险提示，YYYY-MM-DD |

### 6. 媒体订单不能作为 confirmation

见 R4 spec §6：`a-share-r4-thesis-bucketing-announcement-calibration.md`。R5 不重复维护该规则，避免 confirmation 口径分叉。
